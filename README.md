# Bloch Sphere Visualizer

Interactive 3D visualizer for single-qubit quantum gate operations, with hardware backend comparison between IBM and Alice & Bob.

**Live demo:** https://m-uppet.github.io/bloch-sphere-visualizer/

---

## What it does

- Renders a qubit state as a vector on the Bloch sphere (unit sphere in 3D)
- Snap to any of the 6 cardinal states: |0⟩, |1⟩, |+⟩, |-⟩, |i⟩, |-i⟩
- Apply single-qubit gates (X, Y, Z, H, S, S†, T, T†, SX, SX†, I) — the vector updates instantly to the correct result
- Switch between **IBM** and **Alice & Bob** backends to see which gates are supported and how they decompose into native hardware operations
- Hardware steps shown per gate click, with virtual (frame shift) vs physical (pulse) distinction

## Physics

A pure qubit state |ψ⟩ = α|0⟩ + β|1⟩ maps to a point on the unit sphere via:

```
x = 2·Re(α*β)    y = 2·Im(α*β)    z = |α|² - |β|²
```

Gate math is computed exactly from 2×2 complex matrix multiplication — no approximation.

> Hardware decompositions are derived from Qiskit emulators and may not reflect real hardware behaviour.

|---|---|

## Local development

```bash
npm install
npm run dev          # dev server at localhost:5173
npm run test:unit    # gate math unit tests
npm test             # Playwright E2E tests
npm run build        # production build
```

## Project structure

```
src/
  math/
    complex.ts         complex number arithmetic
    statevector.ts     StateVector type, blochFromState(), cardinal states
    gates.ts           gate matrices + applyGate()
    decompositions.ts  types for gate_decompositions.json
  renderer/
    scene.ts           Three.js scene (sphere, axes, labels, state vector)
    animator.ts        bloch-output DOM updater
  ui/
    style.css
  main.ts              wiring — event listeners, backend selector
public/
  gate_decompositions.json   hardware decompositions per backend (from qiskit-playground)
unit/
  gates.test.ts        38 tests covering all gates × cardinal states
tests/
  index.spec.ts        page load smoke test
  bloch.spec.ts        gate UI wiring test
```

## Gate decompositions

`public/gate_decompositions.json` is generated by `gate_decomposer.py` in [qiskit-playground](https://github.com/m-uppet/qiskit-playground) and defines per-gate hardware steps for each backend. Re-run the script after any Qiskit or backend version change, then copy the file here.

# Bloch Sphere Visualizer

Personal project to help me understand better quantum circuits and gates.

**Live demo:** https://m-uppet.github.io/bloch-sphere-visualizer/

---

## Tabs

**Bloch Sphere** — single-qubit gate explorer. Apply gates (X, Y, Z, H, S, S†, T, T†, SX, SX†, I), snap to cardinal states, and see how each gate decomposes on IBM vs Alice & Bob hardware.

**Circuit** — multi-qubit circuit debugger. Type a circuit (or pick Bell / GHZ / Grover), step through it gate by gate, and watch the probability histogram evolve.

## Local development

```bash
npm install
npm run dev      # dev server at localhost:5173
npm test         # Playwright E2E tests
```

## Gate decompositions

`public/gate_decompositions.json` is generated by `gate_decomposer.py` in [qiskit-playground](https://github.com/m-uppet/qiskit-playground) and defines per-gate hardware steps for each backend. Re-run the script after any Qiskit or backend version change, then copy the file here.

The next step is a Flask backend that exposes Qiskit dynamically — the frontend would call it to run arbitrary circuits, get statevectors, and fetch live gate decompositions for any backend instead of relying on a pre-generated JSON file.
